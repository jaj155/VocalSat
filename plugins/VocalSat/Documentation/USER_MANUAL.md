**Version v0.0.0**

## Installation
See the installer for installation instructions.

## Parameters
- **Drive** (0.0 - 24.0 dB): Amount of pre-gain into the saturation stage.
- **Tone** (-100.0 - 100.0 %): Post-saturation tilt EQ.
- **Mix** (0.0 - 100.0 %): Dry/wet blend.
